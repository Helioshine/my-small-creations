# FPV 穿越机模拟器 · 软件介绍

> 一款运行在安卓平板/手机上的第一人称 FPV 穿越机模拟器。
> 真四轴动力学 · 6 张关卡 · 触屏双摇杆 / 实体遥控器 / 键盘三种输入 · 自定义地图编辑器 · 完全离线。

**最新版本**：v32　|　**包名**：`com.dsh.fpv`　|　**体积**：2.1 MB（APK）　|　**权限**：无

---

## 一、这是什么

这不是"贴图飞来飞去"的玩具。它把一架真实穿越机的全部控制链路搬进了安卓设备：

```
摇杆 → 期望角速度(expo) → PID 角速度环 → 力矩需求 → 四电机混控
     → 电机一阶滞后 → 推力/反扭矩 → 刚体积分 → 碰撞解算
```

所以下面这些特性是**自然涌现**的，不是写死的：

- 悬停杆量约 30%（推重比 7:1 + 1.6 次方油门曲线）
- 满舵横滚约 588°/s，阶跃响应 92ms，松杆回中 96ms
- **低油门时电机余量小、角速度上不去**；高油门更灵活
- 偏航权限弱于横滚（螺旋桨反扭矩的物理现实）
- 电压下降后动力变弱，飞到最后会"没劲"
- 撞柱会反弹并损失速度，法向撞击 > 7 m/s 判定炸机

物理层是**零依赖的纯 JS 模块**，不依赖 DOM 与渲染，因此可以在 Node 里直接跑 47 项自动化测试。

## 二、核心功能

### 1. 飞行

| 功能 | 说明 |
|---|---|
| 飞行模式 | 自稳（松手回平）/ 手动（全速率控制） |
| 手感预设 | **新手 / 竞速 / 花飞** 三套一键切换 |
| 手感曲线 | EXPO、最大角速度、油门曲线、死区、摇杆尺寸全部可调 |
| 物理调参 | 推重比、空气阻力、电机响应时间、风速，滑杆实时生效 |
| 相机 | 视场角、镜头俯仰、画面翻转 |
| 音效 | Web Audio 实时合成：电机啸叫随油门变调、风噪随速度、穿门提示、炸机闷响、完赛三连音（无素材文件） |

### 2. 关卡

6 张地图，每张有**独立地形**（叠加正弦高度场，同一条函数驱动渲染顶点、物理碰撞、障碍物就位）：

| 地图 | 难度 | 地形起伏 | 特色 |
|---|---|---|---|
| 新手训练场 | ●○○○○ | ±2.5 m | 五步新手引导；三档赛道（入门/标准/挑战） |
| 环形赛道 | ●●○○○ | ±1 m | 椭圆竞速线，10 门 × 3 圈 |
| 城市峡谷 | ●●●●○ | **±14 m** | 6×6 街区大城市，爬升 70 m、俯冲钻桥洞、绕塔、定点降落 |
| 峡谷穿越 | ●●●●○ | ±7 m | 低空贴谷，第 4 目标为岩柱缝隙 |
| 仓库室内 | ●●●●● | 0 | 封闭空间 + 双排立柱 |
| 高地巡航 | ●●○○○ | **±11 m** | 台地大回环 |

### 3. 目标类型（不只是穿门）

| 目标 | 判定规则 |
|---|---|
| **圆环门** | 平面穿越 + 落在圆内 + 方向正确 |
| **桥洞 / 缝隙** | 矩形口：横向在开口内、纵向在区间内 |
| **绕塔** | 累计绕行角度达到 360°（离开半径带清零） |
| **定点降落** | 进入平台上方、离地 <1.6 m、速度 <2.5 m/s、保持 1.2 s |

HUD 实时显示当前目标与进度（如 `绕塔 210°/360°`、`降落 0.8/1.2s`）。

### 4. 新手引导

进入新手训练场自动触发五步引导，达成条件才推进：

1. 向上推左摇杆起飞（升到 3 m 以上）
2. 油门收到中间保持悬停（约 30% 杆量，3 秒）
3. 左右推右摇杆横滚（松手回平）
4. 前后推右摇杆俯仰（向前 = 低头加速）
5. 穿过第一道门

### 5. 自定义地图编辑器

俯视 2D 画布编辑器（不受 GPU 限制，任何设备可用）：

- **工具**：拖动 / 塔 / 门 / 出生点 / 移动 / 删除
- **参数**：塔半径与高度、门半径/高度/朝向、视图缩放
- **保存前体检**：门不能埋进塔里、门间距、出生点离障碍 ≥2 m，不通过会列出具体问题
- **导入导出 JSON**，可分享与备份
- 保存后可**立即试飞**

### 6. 输入

| 输入 | 油门 | 偏航 | 俯仰/横滚 |
|---|---|---|---|
| 触屏 | 左侧上下（松手保持） | 左侧左右（回中） | 右侧拖动（回中） |
| 实体遥控器 | 默认轴 2 | 轴 3 | 轴 0 / 1 |
| 键盘 | W/S | A/D | ↑↓ / ←→ |

- **浮动摇杆**：手指按在哪，摇杆环就出现在哪，消除"视觉圆 vs 判定区"的错位
- **实体遥控器**：APK 用 `onGenericMotionEvent` 原生读取 HID，绕开 WebView 不支持 Gamepad API 的限制
- 通道监视 + 一键校准，判断"哪一路反了"最直接

### 7. 画面

- three.js r166，阴影、雾效、渐变天空穹顶
- **PolyHaven CC0 写实模型**（树 / 岩石 / 油桶 / 木箱）+ Kenney CC0 建筑
- 程序化细节层：楼顶压顶、窗带、树木岩石、22 座远山
- 贴图与模型全部 base64 内嵌，**单文件离线，不产生任何网络请求**

## 三、版本更新记录

### v32 · 转向更灵敏
- 偏航力矩系数 0.016 → **0.032**（翻倍）
- 偏航速率上限提升到横滚的 85%
- 效果：悬停油门满偏航 268 → **493°/s**，55% 油门起转 t90 170 → **125 ms**

### v31 · 修复偏航翻滚（重要）
- **修复混控矩阵符号错误**：偏航原来写成"三个电机减、一个加"，导致纯偏航输入同时产生俯仰与横滚力矩（实测 wx=-124°/s、wz=+136°/s），表现为"乱转后把机头对准地面再旋转"
- **加入混控缩放**（Betaflight 做法）：电机越界时等比缩小差动部分，而不是各自削顶；修复满偏航时推力暴涨、窜高 13.9 m 的问题
- 效果：纯偏航的俯仰/横滚角速度归零，满偏航 2 s 航向干净转过 113°，高度仅变化 0.28 m
- 新增**通道解耦回归测试**：纯偏航不产生俯仰/横滚、纯横滚不产生偏航、纯俯仰不产生横滚

### v30 · 参照开源引擎补全动力学
- 参考 [RotorPy](https://github.com/spencerfolk/rotorpy) 与开源多旋翼模型，补齐三块缺项：
  - **旋翼阻力**（与推力成正比）→ 转弯"抓地"感，水平极速 141 → 136 km/h
  - **电机升降速不对称**（电调主动刹车）→ 松杆更干脆
  - **电池电压下陷** → 低电量动力衰减，20% 电量时同样油门已无法悬停
- 物理测试 38 → 41 项

### v29 · 地图玩法重做
- 新增三类目标：**桥洞、绕塔、定点降落**，游戏与测试共用同一份判定模块（`objectives.js`）
- **城市彻底重做**：6×6 街区、街道宽 26 m、35 栋建筑（16~82 m）、地形 ±14 m、中央地标双塔
- 航线全程沿街道：爬升 70 m → 俯冲 10 m 钻跨街天桥 → 绕塔一圈 → 定点降落
- 训练场"挑战"路线末尾加降落平台；峡谷穿越第 4 目标改为岩柱缝隙

### v28 · 城市与手感修正
- 大城市重构、地形起伏、门间高差可达 60 m
- **修复积分卷绕**：满杆时积分继续累积，回中后残余推力导致"回正了还在转"；改为饱和即停止积分 + 回中快速泄放
- **摇杆改浮动基座**并放大（直径 150 → 190 px，圆点 60 → 74 px）

### v27 · PolyHaven 写实模型
- 接入 PolyHaven CC0 资产，并用本地流水线加工（`gltf-transform` + `meshoptimizer`）：
  - 岛树：160 万面 → **5337 面**（789 KB）
  - 苔藓岩石：63k → 1282 面（135 KB）
  - 油桶 440 面、塑料箱 10270 面
- 处理方式：剥离法线/粗糙/AO 贴图、贴图降到 512 px、二次误差减面
- 按包围盒自动归一化后实例化摆放

### v26 · PID 控制环
- 角速度环由**纯 P 改为 PID**（积分消稳态误差、微分抑制过冲）——这是"奇妙的线性感"的根因
- 摇杆输入加一阶平滑（22 ms），贴近真机遥控 + 飞控
- 接入首批 CC0 3D 模型（Kenney City Kit）

### v25 · 地形与分难度赛道
- **每张地图独立地形**，同一条高度函数驱动渲染、物理碰撞、障碍物就位
- 新手训练场三档赛道：入门（3 门）/ 标准（5 门）/ 挑战（5 门 + 降落）
- 物理调参页签（推重比/阻力/电机响应/风速）
- 三档手感预设改为 **新手 / 竞速 / 花飞**

### v24 · 自定义地图与画面修复
- **自定义地图编辑器**（俯视 2D 画布）
- **修复画面频闪**：相机近裁面 0.05→0.15、网格改用 polygonOffset、太阳按 8 m 网格吸附
- 摇杆加大
- 新增程序化建模细节层：楼顶压顶、窗带、树木岩石、22 座远山

### v23 · 可玩性稳定版
- 修复 HUD 元素重叠（小屏时按钮与摇杆冲突）
- 修正四元数顺序问题（曾导致画面上下颠倒）
- 中空解算不再冻结，改为自由落体
- 音频实例复用，修复内存泄漏

### v22 · 首个公开版

## 五、安装

1. 传输 `FPV-fpv-sim-v32.apk` 到安卓设备
2. 允许"安装未知来源应用"
3. 安装后直接打开

**系统要求**：Android 6.0（API 23）及以上，支持 WebGL2 的 GPU。应用不申请任何权限。

## 六、已知限制

- 需要能运行 WebGL2 的设备，极老机型会提示无法创建上下文
- 实体遥控器在 APK 内原生读取；网页版依赖浏览器 Gamepad API（部分机型需先插遥控器再刷新）
- 触屏摇杆是"相对拖动"式，松杆后油门保持，符合真机习惯
- 悬停油门（约 30%）下偏航起转较慢——这是真实四轴的电机余量限制，不是 bug，想要更跟手就把油门加大
